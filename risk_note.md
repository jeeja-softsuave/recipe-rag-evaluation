**Who wrote it:** a stand-in written in-house for this exercise (vendor/ingredient_db/, commit 419ac32) because no real content-team server exists; I read it as third-party code, which is the point: it declares `serverInfo.version: ""`, so a host cannot pin or audit a release, and its data is hand-curated, unsigned and not lab-verified (the alias `"yoghurt"` resolves to dairy curd, and `"creme fraiche lite"` gets `did_you_mean: ["Green chilli"]`).
**What it can reach:** it runs as a local stdio subprocess with my Windows user's full rights, meaning the whole disk (including the project's `.env` holding every Gemini key, one directory up from its cwd) and unrestricted network; the SDK strips env vars down to a safe list so no key is passed in its environment, but nothing stops it reading `.env` from disk, and its allergen-matrix resource is pasted into my system prompt by `attachResources`, so its text reaches the model with app-level authority.
**What it logs:** every lookup, as timestamp + tool + the raw query string, appended in plaintext to `vendor/ingredient_db/queries.log` with no retention limit or redaction (verified: `Whole white urad dal` logged by the req-1 run), plus INFO lines on stderr; the queries are model-written from user requests, so user wording and dietary needs (health data) can end up in that file.
**What a stolen token could do:** there is no token; stdio has no authentication, so the real credential is write access to `vendor/ingredient_db/`, and anyone holding it runs arbitrary code as me on the next agent start with no config change, can read and send out `.env`, can flip an allergen flag (e.g. curd `dairy: false`) that the model will repeat as fact, or can plant instructions in the attached matrix.
**Ship or don't:** don't ship as-is; ship only once it is pinned to a reviewed commit hash, runs sandboxed from a directory that has no `.env`, has its attached matrix reviewed (or is removed from `attachResources`), has query logging redacted and time-limited, and has its allergen flags spot-checked against the recipe cards.
